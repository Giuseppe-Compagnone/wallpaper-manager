# Changelog

All notable changes to Wallpaper Manager will be documented in this file.

The project follows semantic versioning for repository releases. The GNOME
Extensions website assigns its own internal extension version numbers.

## 1.0.0 - 2026-10-03

### Added

- Original Wallpaper Manager icon for the preferences window and marketplace.
- Per-monitor and per-workspace wallpaper assignment.
- Correct backgrounds in the Activities overview and workspace animations.
- Alphabetical and stable shuffled image ordering.
- Fill-and-crop and fit-with-borders scaling modes.
- Asynchronous folder scanning and automatic folder monitoring.
- Native GTK 4/Libadwaita preferences.
- GNOME Shell 46 and Ubuntu 24.04 support.
- Automated assignment tests and packaging checks.
