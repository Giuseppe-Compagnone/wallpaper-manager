# GNOME Extensions listing

## Icon

Use `extension/icons/wallpaper-manager.png`.

## Name

Wallpaper Manager

## Short description

Use a different local wallpaper on every monitor and workspace.

## Full description

Wallpaper Manager assigns images from a local folder across every physical
monitor and GNOME workspace. Each image is used before the list repeats.

The correct image is visible on the desktop, in the Activities overview and
during workspace-switch animations. Choose alphabetical or stable shuffled
ordering, and select fill-and-crop or fit-with-borders scaling.

Wallpaper Manager works entirely offline and does not collect data.
